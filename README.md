# Serbest Kick

Android için 3D serbest vuruş oyunu (Godot 4.6). Plan: [docs/PLAN.md](docs/PLAN.md).

- **Tarayıcıda dene:** https://crzyxpo000-max.github.io/serbestkick/
- **APK:** Actions sekmesinde son "Derleme" çalışmasının `serbestkick-debug-apk` çıktısı.

Oyun: kariyer (sezon, hoca güveni, mağaza), hızlı maç ve antrenman. Yayın adımları: [docs/RELEASE.md](docs/RELEASE.md).

Testler: `godot --headless --path . --script res://tests/run_tests.gd`
